# 对话分组整理 Skill

## 触发条件
手动触发，或由每月定时工作流调度执行。

## 步骤

### Step 1：列出所有对话
调用 `extended_chat:list_chats` 获取全部对话列表（limit设为50+）。

### Step 2：筛选未分组对话
找出标题中 **不包含** 以下前缀的对话：
- `[技术]`
- `[游戏]`
- `[学习]`
- `[小说]`
- `[日常]`

### Step 3：对每条未分组对话进行分类
根据标题内容判断属于哪个分组：

#### 分类规则

| 分组 | 匹配关键词 |
|------|-----------|
| **`[技术]`** | 编程、开发、APK、逆向、反编译、GitHub、代码、bug、修复、魔改、串流、AI、模型、工作流、skill、agent、部署、配置、token、哈希、检测、校园扫描、高斯泼溅、3D、虚幻、文件、大模型 |
| **`[游戏]`** | 常见游戏名称（射击类/竞速类/手游等）、封号、玩游戏、通行证、北伐、模组 |
| **`[学习]`** | 高考、作文、阅读、句子、素材、检讨、作业、考试 |
| **`[小说]`** | 小说平台名、常见网文名、下载小说、看书 |
| **`[日常]`** | 以上都不匹配的归为此类（WiFi、法律、聊天、书法、备份等通用话题） |

### Step 4：执行重命名
对每条未分组对话调用 `extended_chat:rename_chat`，加上对应的前缀标签。

### Step 5：汇报结果
输出本次整理的统计：
- 处理了多少条对话
- 各分组分别新增了多少条
- 剩余未分组数量（应为0）

## 约束
- 不要修改已有前缀标签的对话
- 不要删除任何对话
- 如果对话标题包含敏感内容，保留原标题不变，仅加前缀
- 对话消息数为 0 且无内容的，可以删除（但需要用户确认）
