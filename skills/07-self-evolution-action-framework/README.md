# 自进化行动框架

批判/行动分层协作：批判层只输出报告，行动层执行修复。内置 S1-S4 策略模块（包索引自更新/记忆版本清理/规则冲突修复/对话碎片整理）+ 外部资源优先搜索强制规则（6 维评判标准 + 适配决策 + 淘汰记录模板）。

## 安装

1. 下载本目录 zip 包
2. 解压后将 `07-self-evolution-action-framework` 文件夹放入平台的 skills 目录（如 `/sdcard/Download/Operit/skills/`）
3. 确保目录内含 SKILL.md，平台会自动识别
