# 任务规划与执行系统

三层编排架构（规划引擎→协作看板→子Agent执行器）+ 6 条行为规则（并行优先/自动桥接/轮询/仪表盘/批量清理/优先级）+ 10 步并行标准工作流 + 并行判定标准。纯编排方案，任何具备多Agent能力的平台均可落地。

## 安装

1. 下载本目录 zip 包
2. 解压后将 `06-task-orchestration-system` 文件夹放入平台的 skills 目录（如 `/sdcard/Download/Operit/skills/`）
3. 确保目录内含 SKILL.md，平台会自动识别
