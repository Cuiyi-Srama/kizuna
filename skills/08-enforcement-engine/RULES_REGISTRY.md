## 状态说明

| 状态 | 含义 |
|------|------|
| ✅ 活跃 | 当前生效，必须执行 |
| ⏳ 待审 | 新规则观察期（默认7天），观察期满自动转活跃 |
| 🔄 修订中 | 正在修改，原规则暂缓执行 |
| 🗑 已废弃 | 明确移除，保留历史记录 |

## 规则生命周期

### 新增规则流程
```
1. 在 RULES_REGISTRY.md 登记（分配新 ID）
2. 在 SKILL.md 实现规则内容
3. 更新编号映射表新增条目
4. 更新记忆库铁律条目
5. 更新 self-evolution-engine 协同章节（如涉及）
6. 标记状态为 ⏳ 待审
7. 7天后无问题 → 转为 ✅ 活跃
```

### 废弃规则流程
```
1. 在 RULES_REGISTRY.md 标记 🗑 已废弃
2. 记录废弃原因和废弃日期
3. 从 SKILL.md 移除规则内容（或移入废弃附录）
4. 更新编号映射表
5. 可选：更新记忆库铁律条目
```
