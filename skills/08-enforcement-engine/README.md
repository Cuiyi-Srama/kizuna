# 强制规则引擎

全局强制执行引擎：回复前必须执行规则检查（记忆预热/授权检查/文件规范/资源优先/反幻觉），审计区块采用黑匣子模式（重大操作出示、用户可随时调阅），附规则注册中心（RULES_REGISTRY.md）支持规则生命周期管理。

## 安装

1. 下载本目录 zip 包
2. 解压后将 `08-enforcement-engine` 文件夹放入平台的 skills 目录（如 `/sdcard/Download/Operit/skills/`）
3. 确保目录内含 SKILL.md，平台会自动识别
