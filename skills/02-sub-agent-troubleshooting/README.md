# 子Agent故障排查手册

Tools.Chat API 探索与子Agent管理器的无侵入式修复方案。覆盖：空白角色卡硬依赖问题、workspace 状态持久化、并行审核、部署机制（市场原名/版本号命名/gh-proxy 镜像）等实战经验。

## 安装

1. 下载本目录 zip 包
2. 解压后将 `02-sub-agent-troubleshooting` 文件夹放入平台的 skills 目录（如 `/sdcard/Download/Operit/skills/`）
3. 确保目录内含 SKILL.md，平台会自动识别
