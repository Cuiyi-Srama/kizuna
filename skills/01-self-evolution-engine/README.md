# 自进化引擎（全局强制执行版）

AI 自我批判技能：资源优先是自我批判的第一维度。内置 5 维批判框架（效率审查/隐式需求遗漏/假设合理性/边界覆盖/输出质量）+ 外部资源优先搜索规则（平台市场>GitHub>npm>社区），强制'先用现成→改造→重构'三级决策链，杜绝盲目造轮子。

## 安装

1. 下载本目录 zip 包
2. 解压后将 `01-self-evolution-engine` 文件夹放入平台的 skills 目录（如 `/sdcard/Download/Operit/skills/`）
3. 确保目录内含 SKILL.md，平台会自动识别
